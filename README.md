# 🚗 AI Driver Drowsiness Detection System

An AI-powered Driver Monitoring System developed using **Python, OpenCV, MediaPipe Face Mesh, and YOLOv8**. The system detects **driver drowsiness**, **yawning**, and **mobile phone usage** in real time and triggers an alarm to improve road safety.

## ✨ Features

- 😴 Driver Drowsiness Detection
- 🥱 Yawning Detection
- 📱 Mobile Phone Detection using YOLOv8
- 🔔 Real-time Alarm System
- 🎥 Live Webcam Monitoring

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe Face Mesh
- YOLOv8 (Ultralytics)
- Pygame

## 📂 Project Structure

```
DriverDrowsinessDetection/
```

## ⚙️ Installation

```bash
git clone https://github.com/AnkurSingh0702/DriverDrowsinessDetection.git

cd DriverDrowsinessDetection

pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python main.py
```

## 📸 Output

- Detects closed eyes
- Detects yawning
- Detects mobile phone usage
- Plays an alarm when drowsiness is detected
